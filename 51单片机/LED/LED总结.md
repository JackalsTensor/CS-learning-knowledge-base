实验平台：

- 单片机：STC89C52RC

```text
低电平点亮
```

| 电平 | LED状态 |

| 0 | 亮 |

# LED闪烁实验

## 延时函数

```c
void Delay(unsigned int t)
{
    unsigned int i,j;

    for(i=t;i>0;i--)
        for(j=110;j>0;j--);
}
```

作用：

```text
通过空循环消耗CPU时间，实现延时效果
```

---

## D1闪烁

```c
#include <REGX52.H>

void Delay(unsigned int t)
{
    unsigned int i,j;

    for(i=t;i>0;i--)
        for(j=110;j>0;j--);
}

void main()
{
    while(1)
    {
        P2_0 = 0;
        Delay(500);

        P2_0 = 1;
        Delay(500);
    }
}
```

实验现象：

```text
D1亮
↓
等待
↓
D1灭
↓
等待
↓
循环
```

# 流水灯实验

```c
#include <REGX52.H>

void Delay(unsigned int t)
{
    unsigned int i,j;

    for(i=t;i>0;i--)
        for(j=110;j>0;j--);
}

void main()
{
    while(1)
    {
        P2=0xFE;
        Delay(500);

        P2=0xFD;
        Delay(500);

        P2=0xFB;
        Delay(500);

        P2=0xF7;
        Delay(500);

        P2=0xEF;
        Delay(500);

        P2=0xDF;
        Delay(500);

        P2=0xBF;
        Delay(500);

        P2=0x7F;
        Delay(500);
    }
}
```

实验现象：

```text
D1 → D2 → D3 → D4 → D5 → D6 → D7 → D8
```

形成流水灯效果。
